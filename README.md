# กล้องบอก กม. ทล.117 ตอน 1

เว็บแอปถ่ายรูปที่สแตมป์ กม. จากแนวศูนย์กลางทาง (℄) เช่น `62+000.000 LT` / `RT` (ตามทิศทาง กม. เพิ่มขึ้น 62 → 79)

- คำนวณจาก GPS มือถือ → UTM Zone 47N → ฉายลงแนว ℄ ที่สร้างจากตารางค่าพิกัดเขตทาง ทล.117 ตอน 1 (20 หมุด, กม.62+000.000–79+000.000)
- บนรูป: กม. + LT/RT, ระยะห่างจาก ℄, รายการงาน, วันเวลา, N/E, Lat/Long, ความแม่นยำ GPS (ฝัง GPS ใน EXIF ด้วย)
- ใช้กล้องมือถือ/รูปในคลังได้ (อ่านพิกัดจาก EXIF) และแก้ กม. เองได้
- นำเข้าแนวทางอื่นเป็น CSV ได้ (`STA,N,E` หรือรูปแบบตารางพิกัดเขตทาง)
